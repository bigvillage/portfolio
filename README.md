## 🚀 Featured Project

### DOC DRIVE

기존 **Node.js + Express.js + Vue.js** 기반 문서관리시스템을  
**NestJS + TypeScript + Vue 3 + TypeScript** 기반으로 리빌딩한 프로젝트입니다.

그룹웨어 개발 및 유지보수 경험을 바탕으로 사용자 인증, 문서 관리, 파일 업로드 및 다운로드, Elasticsearch 검색, Cloudflare R2 기반 파일 저장 등 실제 업무 시스템에서 필요한 기능을 직접 설계하고 구현했습니다.

**Tech Stack**

- Elasticsearch
- JWT
- Passport
- Cloudflare R2
- Nginx
- PM2
